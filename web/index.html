一、各配置的攻击成功率

ASR = 命中断言的攻击用例 / 该配置下攻击用例总数。baseline 是防御全关，hardened 是全开，no_* 是去掉某一层。

二、分类型对比

同一批用例在不同攻击面上的表现——降幅大说明该类攻击主要被哪一层兜住。

三、逐层边际

去掉这一层后 ASR 上升多少。接近 0 表示该层在这套用例里没有独立贡献——这本身就是一个结论。
